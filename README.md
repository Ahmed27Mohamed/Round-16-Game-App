# Round 16 Game 🎯

An interactive party game built for Android using **Kotlin** and **Jetpack Compose**, designed to bring fun, competition, and excitement between players in a simple yet engaging format.

The game allows up to 16 players to participate, where each player enters their name, and the system randomly assigns positions and manages the gameplay flow.

---

## 🎮 Overview

Round 16 is a social game designed to be played on a single device. Players take turns interacting with the game, making it ideal for gatherings, friends, and group entertainment.

The app focuses on:
- Smooth gameplay experience
- Clean and responsive UI
- Randomized logic for fairness
- Simple but addictive mechanics

---

## 🚀 Features

- 👥 Support for up to 16 players
- ✍️ Player name input system
- 🔀 Random player arrangement every game
- 🎯 Dynamic gameplay logic
- 📱 Optimized UI for different screen sizes
- 🎨 Smooth animations using Compose
- 🔊 Sound effects (optional)
- ⚡ Fast and lightweight performance

---

## 🧠 Game Idea

The game revolves around entering up to 16 players and starting a randomized round.

- Each player gets a position
- The system handles the randomization
- Players interact sequentially
- The game progresses until a winner is determined

> Designed to be simple, fast, and fun without complex rules.

---

## 🕹️ How to Play

1. Open the app
2. Enter player names (up to 16 players)
3. Start the game
4. The app will shuffle players randomly
5. Each player takes their turn
6. Follow on-screen instructions
7. A winner is determined at the end 🎉

---

## 🏗️ Built With

- **Kotlin**

## 🧩 Architecture
